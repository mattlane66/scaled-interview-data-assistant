# Mattress example walkthrough

This example demonstrates one bounded decision episode.

- Point A is repeated morning pain and lost functioning—not “needs a mattress.”
- Path Y includes rotation, a topper, the couch, research, and delay.
- The hotel stay is evidence that changed Alex’s belief; it does not prove a medical cause.
- The nearby return path reduces switching anxiety.
- Point B is recovered morning functioning—not memory foam or a return policy.
- The observed Path X result is `UNKNOWN` because the interview happened before use.

The card cites every important claim, separates verbatim evidence from interpretation, and shows the
machine-facing ownership fields required by the deterministic pipeline.
